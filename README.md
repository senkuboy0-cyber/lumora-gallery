# Lumora Gallery

Lumora is a modern Android gallery app built with Kotlin, Jetpack Compose, Material 3, MVVM, Clean Architecture, Flow, Room, DataStore, ML Kit, and WebRTC-oriented sharing services.

## Requirements

- JDK 21
- Android SDK 35
- Android Studio with Android Gradle Plugin 9.2.0 support

## Build

```bash
./gradlew assembleDebug
```

No API keys are hardcoded. AI provider settings are configured by the user in Settings and stored by the app.
